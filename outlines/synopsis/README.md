# 集纲索引

四部 50 集集纲，每集一段成文剧情梗概（场景、出场人物、剧情推进、关键台词、结尾钩子）。

与 `outlines/episodes/` 下的**分集表**是两层东西：分集表是一集一行的表格，一屏看完全剧节奏和钩子类型分布，用于排结构；集纲是每集一段两三百字的叙述，用于定人物动作和台词方向，是开写剧本前的最后一层。

## 每部的命门（写剧本时最容易写坏的地方）

- **回村的第一百天**：刘凤不能写成反派。她每次刻薄背后都要有一个具体的疲惫。第 33 集"我雇你，一个月四千，签合同"是全剧题眼。
- **我妈的菜谱**：女儿不是势利眼，是从小没人告诉过她"家务是本事"。第 26 集她在评论区看见母亲名字那一下要给足特写。
- **我女儿也姓林**：婆婆不能只是恶婆婆，她自己就是重男轻女的产物。第 35 集那句"那是我们家秀荷开的"和第 45 集的保温桶，是她全部的忏悔方式。
- **房本上的第一个名字**：裴敏不能变成冷冰冰的赢家。她所有的克制都来自第 13 集母亲照片被扣过去那一下。

## 六个结构点，四部都对齐了

1. 第 1 集前 8 秒进冲突，没有铺垫开场。
2. 第 3 集主角第一次说"不"。
3. 第 15-16 集付费卡点，停在最痒处。
4. 憋屈段不超过 7 集，且每集主角必须主动做一件事。
5. 大爆点间隔 10-14 集。
6. 最后一集兑现大纲里写死的那个结局画面。
