《房本上的第一个名字》爆点最密、憋屈段最短（只有 10-16 这一段），是四部里最"顺"的一部；《我妈的菜谱》第 27-32 集是唯一需要盯的注水风险段，每份分集表末尾的"自查"里都写清了对应的补救办法。

## 每份文件里有什么

- 规格与付费卡点
- 核心信息差及其泄露 / 破裂的具体集数
- 主要人物（底线 / 抓手 / 软肋，反派的正当理由）
- **50 行分集表**：集 ｜ 场景 ｜ 核心事件 ｜ 情绪·爽点 ｜ 结尾钩子 ｜ 钩子类型·强度
- 自查：钩子类型分布、爽点密度、大爆点间隔、这部的命门、成本提示

钩子类型缩写统一为：闯（闯入者）、称（称呼揭穿）、证（物证曝光）、变（变天台词）、危（新危机）、情（情感反转）；强度为弱／中／强／弹。
