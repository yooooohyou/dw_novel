## 先做哪一部

如果只投一部试水，建议各选一部**低成本 + 强差异化**的：

- 题材一选 **04《我在婆家当保洁》**。装穷有真实的职场质感，全部戏在一栋写字楼里就能拍完，场景成本最低；"外包/正式"这条线是同类剧里没人碰过的。
- 题材二选 **02《这套房，写的是我的名字》**。法律线自带悬念和信息增量，完播率高；场景就是老小区、超市、法院三处，最省。

如果要做**中老年赛道的口碑款**，选题材一的 **03《回村的第一百天》** 和题材二的 **03《免费保姆辞职了》**——这两部的反派都不是坏人，结局的和解才真正兑现"阖家圆满"和"被看见"。
