# 赛道清单

选赛道不是选标签，是选**爽点的兑现方式**。同一个"逆袭"故事，放在战神赛道靠武力兑现，放在豪门赛道靠身份兑现，放在亲情赛道靠悔恨兑现——写法完全不同。

每条赛道给四样东西：核心信息差、爽点公式、常见开局、当下的同质化陷阱。**陷阱那一栏最值钱**——它是让你的本子和市面上几百部区分开的地方。

## 目录

- [男频](#男频)：战神/龙王归来、赘婿逆袭、重生复仇、马甲/扮猪吃虎、系统流

## 男频

### 战神/龙王归来

- **信息差**：主角是执掌千军的战神/隐世强者，家人和市井小人只当他是废物女婿或穷小子。
- **爽点公式**：被当众羞辱（要钱、赶出门、泼酒）→ 忍（为了给亡妻守诺/为了母亲）→ 一个电话/一块令牌/一个下属现身 → 施暴者跪地磕头。
- **常见开局**：五年后归来那天，正撞上妻子被逼相亲 / 岳母的六十大寿上被赶去坐儿童桌。
- **陷阱**：全剧变成"报身份—对方跪—换下一个人—再跪"的循环，二十集后观众麻木。**破法**：让身份揭穿变得有代价（暴露一次就被旧敌盯上），或者给反派一个真正扛得住的靠山，逼主角用脑子而不是用身份。

### 赘婿逆袭

- **信息差**：同上，但主角困在家族内部，日常羞辱来自枕边人和亲戚，更琐碎、更贴身。
- **爽点公式**：家务活、外卖钱、族谱除名这类"小刀子"积累 → 家族生意出事只有他能解 → 全家反过来求他。
- **常见开局**：家族会议上被要求签自愿放弃财产协议。
- **陷阱**：女主角常被写成前期跟着家人一起欺负主角，后期强行洗白，观众不买账。**破法**：让女主从头就有一条自己的暗线（她其实在护着他，只是方式笨拙），洗白才立得住。

### 重生复仇（男）

- **信息差**：主角带着上一世的记忆，知道谁会背叛、哪支股票会涨、哪天会出车祸。
- **爽点公式**：前世的死局在今生被提前拆掉 → 加害者按原剧本行动却处处踩空。
- **常见开局**：在自己葬礼上/被推下楼的瞬间睁眼，回到十年前的清晨。
- **陷阱**：先知优势太强，反派没有还手之力，前二十集之后就没有张力了。**破法**：让重生只覆盖前世的一部分（他死得早，后半段不知道），或者蝴蝶效应让历史提前偏离，先知逐渐失效。

### 马甲/扮猪吃虎

- **信息差**：主角有多重身份（首富、影后、黑客、医圣），一层一层被扒。
- **爽点公式**：每掉一个马甲，围观者的下巴掉一次。
- **常见开局**：以最不起眼的身份进入一个高门槛场合（保安、临时工、旁听生）。
- **陷阱**：马甲太多变成流水账。**破法**：马甲要有情感重量——每个身份对应一个他必须保护的人或一段过去，掉马甲时掉的是秘密不只是牌面。

### 系统流

- **信息差**：只有主角能看见系统面板。
- **爽点公式**：接任务 → 做出旁人无法理解的举动 → 领奖励 → 旁人恍然大悟。
- **陷阱**：系统提示音写成大段旁白，竖屏拍出来只能靠字幕，非常廉价。**破法**：把系统的判定藏进人物行为，让"为什么他要这么干"本身成为悬念。

## 女频

### 闪婚豪门

- **信息差**：随手领证/被安排嫁的那个"穷酸病秧子"，其实是隐形继承人。
- **爽点公式**：被婆家和同事看不起 → 老公真实身份在关键场合曝光 → 势利眼集体变脸。
- **常见开局**：民政局门口两个被各自家庭逼婚的人决定搭伙。
- **陷阱**：女主全程等着男主来救，独立性为零，现在的观众会骂。**破法**：给女主一个自己的专业（医生、修复师、调香师），让她至少解决一次男主解决不了的问题。

### 重生复仇（女）

- **信息差**：她记得自己上一世是怎么被姐妹和丈夫合谋害死的。
- **爽点公式**：把前世别人对她做的事，一件一件原样还回去。
- **常见开局**：被推进手术室摘除器官的瞬间/婚礼当天回到十八岁。
- **陷阱**："复仇"变成纯粹的宅斗互殴，格局小。**破法**：给她一个复仇之外的目标（救活母亲、拿回工厂），复仇是路上的事，不是全部。

### 替身 / 追妻火葬场

- **信息差**：观众早知道她才是当年救他的人，男主不知道；或男主一直把她当白月光的替身。
- **爽点公式**：她转身离开 → 他开始拼图 → 真相揭开时她已经不需要他了。
- **常见开局**：她在病床上听见他对别人说"她不过是个替身"。
- **陷阱**：虐得太久，观众心疼变成心累；或者男主犯的错太大，后期怎么跪都不解气。**破法**：控制虐的长度（不超过 15 集），并让男主的误会有一个**观众能理解**的来源，否则他不是深情是脑残。

### 大女主逆袭

- **信息差**：可以没有身份差，靠能力差——她的专业本事被全场低估。
- **爽点公式**：外行质疑 → 她动手 → 结果说话。
- **常见开局**：被开除的那天，前公司搞砸了最重要的项目。
- **陷阱**：把"独立"写成"逢人就怼"，人物变刻薄。**破法**：让她的强硬有对象——只对施压者硬，对弱者护，人物立刻可爱。

### 甜宠

- **爽点**：不靠打脸靠糖。每集一个"心跳时刻"：手腕被拉住、外套披上肩、深夜的一条消息。
- **陷阱**：没有冲突就没有钩子，甜宠最容易变成流水账。**破法**：外部压力必须持续存在（家族反对、职场竞争、身份隐瞒），糖是在压力缝里给的才甜。

## 中老年赛道

这条线的观众付费能力强、忠诚度高，但**爽点逻辑完全不同**：他们要的不是"我赢了"，是"我被看见了、被后悔了"。

### 婆媳 / 家庭伦理

- **爽点公式**：默默付出被当作理所当然 → 她离开或病倒 → 全家瘫痪 → 悔恨。
- **陷阱**：把恶婆婆写成纯恶魔。**破法**：给她一个自己的委屈来源，观众骂得动情，也能共情。

### 养老 / 认亲

- **爽点公式**：儿女为房产争吵、把老人推来推去 → 老人其实有一笔钱/一个失散的孩子 → 分配那一刻，人心毕现。
- **陷阱**：说教味重。**破法**：让老人自己做出决定并承担后果，不要让旁白讲道理。

### 老年霸总

- 中老年版闪婚/黄昏恋，套路同女频但去掉职场，加进儿女阻挠与旧情往事。

## 其他

### 穿越 / 古装

- **信息差**：现代知识在古代=神迹（急救、玻璃、账本、火药）。
- **陷阱**：古装场景贵。**破法**：把场景压在县衙、后院、客栈三处，靠人物冲突撑，不靠场面。

### 悬疑

- 钩子天然强，但要求编剧对伏笔的控制力更高：每集抛的问号必须在 10 集内有回应，否则观众会觉得被耍。

### 年代

- 靠情怀和时代压迫感，适合亲情与励志。**成本注意**：年代戏的服化道和场景是隐性大坑，慎选。

## 副赛道的搭法

主赛道决定爽点如何兑现，副赛道决定情绪的层次。常见有效组合：

- 战神归来 + 亲情（他忍的理由是女儿）——让纯爽剧有了软肋
- 闪婚豪门 + 大女主（她也有本事）——补上女频最被诟病的短板
- 重生复仇 + 悬疑（她死因另有隐情）——给复仇加一条推理线
- 婆媳 + 认亲（媳妇其实是失散的女儿）——中老年赛道最有效的双重反转

不要叠三条以上。信息差一多，观众记不住，钩子就废了。
