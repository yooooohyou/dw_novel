# 单集剧本模板

复制下面的结构直接填。集头信息块和 `【人物】`、`【钩子】` 标记不要省——制片按它排通告，`scripts/check_script.py` 按它校验。

下面是一集完整示例（估算 70 秒，属于 60-120 秒的正常区间），可以直接当尺子用：台词总量、场景数、钩子的位置都是达标的。

---

第 7 集  《当众下跪》
时长 70″ ｜ 场景：婚宴大厅、大厅门口 ｜ 爽点：管家认主
上集钩子：林晚接到一通神秘电话。

1. 日 / 内 / 婚宴大厅
【人物】林晚、林母、林小雨、宾客若干

林母把股权转让书拍在桌上，纸角划过林晚的手背。

林母（尖利）：跪下，签了它。

林晚：妈，这是我妈留给我的。

林母（冷笑）：你妈？一个死人也配姓林？

林小雨举着手机凑上来，镜头对准林晚的脸。

林小雨：姐，笑一个呀，直播间三万人看着呢。

宾客窃笑。有人举杯，酒液晃出杯沿。

宾客甲：林家白养了她二十年，也该还了。

林晚（垂眼）：还？连我妈的公司一起还？

林母反手一巴掌。林晚的头偏了一下，没躲。

林母：这儿还轮不到你说话。

两个保安上前，一左一右架住林晚的胳膊，把她按向地面。

林小雨（对着镜头）：家人们看好了，这就是白眼狼的下场。

林晚的膝盖离地面还有半寸，停住了。她抬眼看向林母。

林晚：我签。松手。

林母摆摆手。保安退开。林晚攥紧的拳头缓缓松开，接过笔。

她低头，笔尖悬在签名栏上方，停住。

林晚：签之前我问一句。这协议，谁让你拿来的？

林母的手指抖了一下，随即抢过纸拍在她面前。

林母：签你的字！哪来这么多废话。

林晚（很轻）：落款日期是三年前。那时候我妈还没走。

2. 日 / 外 / 大厅门口
【人物】老管家、保镖四人

三辆黑车依次停稳，车门同时打开。老管家整了整袖口，抬手推开大厅的门。厅内的喧哗一寸一寸静下去。

老管家穿过人群，径直走到林晚面前，深深躬身。

【钩子】老管家：小姐，老爷子等您回家。林母手里的红酒杯摔在地上。

## 填写时的检查点

- 第一句台词是不是就带冲突？没有铺垫、没有风景、没有回忆开场？
- 台词最长的一句超过 20 字了吗？
- 场景是不是 1-3 个？同框有名有姓的角色是不是不超过 4 个？
- 爽点有没有围观者在场？（私下的胜利不解气）
- `【钩子】` 是画面或台词，不是心理活动？和前两集的钩子类型重样了吗？
- 时长对得上吗？（台词字数 ÷ 4.5 + 句数 × 0.8 + 动作段落 × 2.5 + 场景数 × 2）

跑一遍机械检查：

```bash
python3 .claude/skills/short-drama-script/scripts/check_script.py 你的剧本.md --target 70
```
