# 竖屏微短剧剧本

## 先理解这门手艺在跟什么较劲

观众不是坐在沙发上看剧，是躺在床上刷。手指悬在屏幕上，每一秒都在决定要不要划走。所以短剧的所有"规矩"都是从同一件事推出来的：**你必须一直欠观众一个答案**。

由此有三个引擎，写任何一集之前先在心里过一遍：

1. **信息差**——观众知道、剧中人不知道。观众知道被羞辱的保洁大妈是集团董事长，于是每一句"你也配"都在为观众攒快感。信息差是短剧最廉价也最强的燃料，一旦被提前揭穿，后面几十集就没得看了，所以**揭穿时机是全剧最贵的资源，要一点一点花**。
2. **钩子**——每集最后 5-10 秒必须打开一个新的问号，而不是关上一个。观众划到下一集不是因为上一集好看，是因为上一集没讲完。
3. **爽点密度**——反派施压 → 主角忍 → 打脸反转，这个循环要短。竖屏观众的耐心大约是 2-3 集；憋超过 5 集不给回报，弃剧率会陡升。

还有一条不写在纸上但决定剧本能不能拍的：**成本**。竖屏短剧通常 7-10 天拍完全剧，5-8 个固定场景，画面里常态只有 1-2 个人。写出"千人广场爆炸""主角开着直升机"就等于把剧本废掉。

## 工作流

先判断用户站在哪一步，然后从那一步接上，不要每次都从头来：

- 只有一个模糊想法 → 从**第 1 步**开始
- 已有题材和人设，缺结构 → 从**第 3 步**开始
- 已有分集梗概，要出成片剧本 → 从**第 4 步**开始
- 拿来一份现成剧本让你改 → 直接跳到 **诊断与改写**

**每完成一步，停下来把结果给用户确认再往下走。** 大纲错一个人设，后面 80 集全要返工；这一步的确认成本远低于返工成本。用户明确说"一口气写完别问我"时，就一次做完，但仍然按顺序把每一层的产物都写出来——跳过大纲直接写剧本，写到第 20 集必然崩。

## 第 1 步：立项卡

一页纸，定死全剧的骨头。字段固定如下，逐条填，不要写成散文：

```
赛道：      （见 references/genres.md，选一条主赛道 + 最多一条副赛道）
一句话故事： 【身份/处境】的【主角】，因为【触发事件】，必须【目标】，否则【代价】。
核心信息差： 观众知道什么，剧中谁不知道，这个差什么时候开始漏、什么时候彻底破
主角目标：  具体、可视、能被拍出来的（"拿回母亲的股权"而不是"证明自己"）
最大阻力：  一个有名有姓的人，不是"命运""偏见"
爽点公式：  被【怎样羞辱】→ 忍到【什么条件】→ 用【什么方式】打回去
结局承诺：  观众追到最后要看到的那一幕（写成一个具体画面）
```

一句话故事写不顺，说明故事本身有洞，别急着往下走——回去改设定，比改到第 40 集才发现便宜得多。

## 第 2 步：人物表

短剧的人物不是"复杂"，是"清晰且有用"。三类，各有各的写法：

**主角（1-2 人）**——必须同时具备"憋得住"和"打得响"。憋得住给爽点蓄力，打得响给爽点兑现。写主角时定死三样：他的底线（越过就必须反击，这是打脸的开关）、他的隐藏牌（能力/身份/靠山，兑现爽点的手段）、他的软肋（母亲、女儿、旧恩人——反派攻击软肋是最省事的加压方式）。

短剧主角最常见的死法是**被动**：连挨十集打不还手，观众看的是憋屈不是爽。主角可以隐忍，但每一集都要**主动做一件事**——哪怕只是不动声色留了个后手。

**对手（1-2 人）**——要蠢得合理。反派不能是笨蛋，否则打脸不解气；他的错误必须来自一个可信的动机：贪、傲慢、笃信主角没背景。给反派一个他自认为的正当理由，打脸时才响。

**工具人（一群）**——出场即立牌子，靠标签活着：势利的婚礼司仪、嘴碎的三姑、拜高踩低的店员。工具人不需要弧光，需要的是**在正确的时刻说出观众想骂的那句话**。他们是爽点的放大器。

每个人物写 60 字以内：一句身份、一句欲望、一句口头禅或标志动作。超过这个长度说明在写小说，不是在写短剧。

## 第 3 步：故事大纲 + 分集表

先画节奏地图，再拆分集。以 80 集为例（60-100 集同理缩放）：

| 段落 | 集数 | 任务 |
|---|---|---|
| 开局 | 1-3 | 7 秒内进冲突，立信息差，第 1 集结尾必须给一个小反转让观众"回本" |
| 立威 | 4-12 | 第一次小规模打脸，兑现爽点承诺，告诉观众这剧值得追 |
| 加压 | 13-25 | 反派升级，主角软肋被攻击，身份险些暴露 |
| 中盘爆点 | 26-40 | 一次大揭穿或大反转，全剧最高潮之一，绝不能把底牌全掀 |
| 二次加压 | 41-60 | 更强对手登场，前期埋的伏笔开始回收 |
| 终局 | 61-80 | 信息差彻底破裂 → 总清算 → 结局承诺兑现 |

两条节奏纪律：**每 2-3 集一个小爽点，每 10 集一个大爆点**；付费短剧的卡点通常设在 15-25 集之间，卡点那一集必须停在全剧最痒的地方（身份即将暴露、耳光即将落下），而不是一个段落的收尾。

分集表用表格，一集一行，写到能直接开写剧本的颗粒度：

| 集 | 主场景 | 核心事件 | 情绪/爽点 | 结尾钩子 |
|---|---|---|---|---|
| 7 | 婚宴大厅 | 林母当众撕毁股权书逼林晚下跪 | 憋屈到顶点 | 大门推开，管家喊出"少爷" |

写分集表时逐行自查：这一集**结束时的处境**和**开始时的处境**必须不一样。一集之内没有状态变化，这集就是水集，删掉或与相邻集合并。

模板见 `assets/outline-template.md`。

## 第 4 步：单集剧本

一集 60-120 秒。以 90 秒为例，对应的量大约是 **180-250 字台词、12-18 句对白、10-15 段动作描写、1-3 个场景**。写超了拍出来就是三分钟，节奏必垮；写少了又撑不满一集。粗略换算：`时长 ≈ 台词字数÷4.5 + 句数×0.8 + 动作段落×2.5 + 场景数×2`，`scripts/check_script.py` 就是按这个算的。

**单集时间轴**（这是短剧和普通剧本最大的区别，务必按它写）：

- **0-8 秒｜接钩**：直接接上集悬念，或直接甩冲突。禁止用交代、铺垫、风景、回忆开场——第一句台词就要带火药味。
- **8-50 秒｜推进**：加压或反击。信息在这里流动，人物做决定。
- **50-85 秒｜转折**：本集的爽点或反转落地，观众的情绪在这里兑现。
- **最后 5-10 秒｜新钩**：抛新问号。常用的几种是——**闯入者**（门被推开）、**称呼揭穿**（有人喊出"少爷"）、**物证曝光**（照片/短信/报告落在不该看见的人眼里）、**变天台词**（"这家公司，从今天起姓林"）、**新危机**、**情感反转**。钩子必须落在**画面或台词**上，不能是心理活动，因为镜头拍不出心理活动。类型库和各自的失效条件见 `references/hooks.md`。

**格式**（照抄这个结构，制片和演员认这个；下面是节选，完整一集见 `assets/episode-template.md`）：

```
第 7 集  《当众下跪》
时长 90″ ｜ 场景：婚宴大厅、大厅门口 ｜ 爽点：管家认主
上集钩子：林晚接到一通神秘电话。

1. 日 / 内 / 婚宴大厅
【人物】林晚、林母、林小雨、宾客若干

林母把股权转让书拍在桌上，纸角划过林晚的手背。

林母（尖利）：跪下签了它。
林晚（垂眼）：妈，这是我妈留给我的。
林母（冷笑）：你妈？一个死人也配姓林？

宾客窃笑。林小雨举着手机在拍。

林晚攥紧了拳，指节泛白——又缓缓松开。

林晚：好，我签。

2. 日 / 外 / 大厅门口
【人物】老管家、黑衣保镖四人

三辆黑车停稳。老管家推门而入，扫视全场，径直走向林晚，深深躬身。

【钩子】老管家：小姐，老爷子等您回家。林母手里的红酒杯摔在地上。
```

**台词规则**（都是为竖屏观众服务的，不是形式主义）：

- 单句 **20 字以内**，超过就拆。观众常常静音看字幕，长句在竖屏上要折三行，眼睛跟不上。
- 一来一回不超过 4 轮，超过就插动作或切场景，否则画面会"死"在两张脸上。
- **禁止独白式交代**。要交代前史，就让两个人吵着交代——信息裹在冲突里才有人听。
- 情绪靠动作，不靠形容词。"她很愤怒"是废话，"她把汤泼在自己身上"能拍。
- 括号里的表演提示每场最多两三处，只标反常的情绪（冷笑、颤抖、突然温柔），常规情绪交给演员。

**场面调度约束**（写的时候就要替制片省钱）：

- 画面里常态 1-2 人，最多同框 4 人；"宾客若干"是背景，不给台词。
- 全剧固定场景控制在 5-8 个，新场景每多一个都要问一句"能不能挪到已有场景"。
- 不写：大规模群演、爆炸、车祸实拍、动物、婴幼儿、复杂特效、大量夜外景、跨城市转场。
- 打戏写成 2-3 个动作节拍即可（"一记手刀，保镖软倒"），不要写武指分镜。

模板见 `assets/episode-template.md`。

## 交稿前自检

写完任意一批集数，逐条过一遍。这些是短剧最常见的死因：

1. 第 1 集前 7 秒有没有冲突？（有铺垫就删掉铺垫）
2. 每一集的最后一句是不是钩子？是不是画面/台词而非心理？
3. 相邻两集的钩子类型是不是重样了？（连着三集"有人推门进来"会麻木）
4. 主角这一集主动做了什么？还是全程挨打？
5. 最长的一句台词多少字？
6. 这一集的场景数、人数、有没有超出成本红线？
7. 信息差有没有被过早揭穿？揭穿之后，下一个悬念是什么？
8. 这一集删掉，故事会不会缺一块？（不会 → 它是水集）

第 2、5、6 条可以用脚本机械地查一遍，比肉眼快也更准：

```bash
python3 .claude/skills/short-drama-script/scripts/check_script.py 剧本文件.md
```

脚本按上面的格式解析，报出每集的估算时长、场景数、最长台词、缺失的钩子标记。它只查形式，不查好坏——过了脚本不等于写得好，但没过一定有问题。

## 诊断与改写

用户拿现成剧本来改时，先跑一遍 check 脚本拿到硬指标，再按这个顺序找病根（从最致命往下）：

**没人看下去** → 钩子问题。检查每集结尾，八成是"关上了问号"而不是打开新的。
**看了但不爽** → 爽点问题。多半是主角憋太久，或者打脸时反派没有当众丢脸——爽点必须**有观众在场**，私下解决的胜利不解气。
**觉得拖** → 水集问题。用自检第 8 条筛，通常能砍掉 15-20% 的集数。
**觉得假** → 动机问题。反派做蠢事没有可信理由，或者主角有能力却不用（"我不想暴露身份"用三次就失效了，必须给具体代价）。
**拍不了** → 成本问题。按上面的调度约束逐场砍。

改写时**给出修改后的完整集**，不要只列意见——用户要的是能直接拍的稿子。同时用一两句说明改了什么、为什么改，方便他判断要不要沿用到其他集。

## 写作时的态度

这些结构是脚手架，不是牢笼。套路之所以是套路，是因为它在几万部剧上被验证有效；但观众同时也在为**新鲜的那 20%** 付钱。稳妥的做法是：结构上老实（钩子、节奏、爽点密度一条不落），细节上使劲——让羞辱的方式、打脸的手段、人物的口头禅是别人没写过的。

用户提出跟这里不一样的要求时，按用户的来。他可能在做一个反套路的项目，或者平台有特定规格。
